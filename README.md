# ☕ Corretto Coffee Shop

A modern Single Page Application for a coffee shop built with Vue 3, TypeScript, Vite, and Tailwind CSS.

## Features

- Vue 3 Composition API + TypeScript
- Tailwind CSS responsive layout
- DummyJSON API integration with search
- Product detail modal
- Shopping cart with localStorage
- Hero image slider
- Reusable component architecture

## Tech Stack

- Vue 3 + TypeScript
- Vite
- Tailwind CSS
- DummyJSON REST API
